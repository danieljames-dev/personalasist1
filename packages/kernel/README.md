# `@aion/kernel`

The AION Kernel v1 is a deterministic lifecycle coordinator for replaceable
participants. It contains no domain behavior, service lookup, persistence, events,
model selection, or vendor integration.

Use the explicitly versioned export:

```ts
import { AionKernelV1 } from "@aion/kernel/kernel/v1";
```

The normative API and lifecycle behavior are documented in
[`docs/api/kernel-v1.md`](../../docs/api/kernel-v1.md) and
[`docs/architecture/kernel.md`](../../docs/architecture/kernel.md).

# @aion/application-preparation

Reference Candidate package for deterministic, evidence-backed application drafts. Outputs are
explicitly marked `Draft — Owner Review Required`; every positive career claim carries a pinned
CareerFact citation. Unknown, missing, conflicting, or unsupported inputs become visible review
items and never invented claims.

The package performs no submission, attestation, signing, job discovery, network access, model
call, embedding, vector storage, or autonomous communication.

See `docs/contracts/application-preparation-v1.md`. This is a Reference Candidate: DG-3 and DG-4b
remain Open, the Object Contract remains Pre-stable, and synthetic tests are not normative fixtures.

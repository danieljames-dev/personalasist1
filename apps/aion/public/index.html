Welcome to AION

AION runs on this computer. Private state lives under the ignored private/aion directory and is excluded from source backups.

The offline deterministic provider is selected by default and performs no network call. A remote provider can receive only the conversation and context you explicitly enable, and you must accept the disclosure first. Credentials are read from an environment variable you name; AION never stores the value.

Imports always begin with a dry run over a path you choose, originals are never modified, and consequential agent actions require an exact one-shot approval. The model can only propose.

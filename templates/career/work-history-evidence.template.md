# Work-history evidence input

This blank owner-input template is for manually selected UTF-8 text. Paste or write only the
content you explicitly want considered in a future, separately authorized ingestion phase.
Opening, reading, or copying this template does not ingest anything.

Tie claims to evidence where possible. Do not invent dates, employers, titles, responsibilities,
accomplishments, metrics, skills, certifications, education, or licenses. Sensitive information is
optional and should be minimized.

Do not include secrets, passwords, tokens, Social Security numbers, full financial-account
information, or unnecessary medical details.

Completed owner copies belong only under ignored private career storage and must never be committed.
This tracked blank template is not a normative conformance fixture.

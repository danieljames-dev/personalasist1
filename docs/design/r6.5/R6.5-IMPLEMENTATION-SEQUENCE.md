## Phase A — Schema & pure state machine (low risk)

**Deliverables**

## Phase C — Owner proof MVP (medium-high)

**Deliverables**

- DPAPI-protected local HMAC secret or platform key (design choice locked in ADR)
- Owner UI process can create proofs
- Operator Host verifies proofs
- Agents never load secret

**Exit criteria**

- S3 replay fails  
- Secret not present in agent env dumps  

**Complexity:** M/H

## Phase D — Operator Host MVP (high)

**Deliverables**

- Windows background process / service  
- Local IPC (named pipe) with OS user ACL  
- Mediated operation tokens: git_read, npm_verify, repo_write, temp_write, handoff_write  
- Working directory jail  
- Output redaction filters  
- Single writer lock  

**Exit criteria**

- Grok path can run verify without Owner typing npm  
- Free-form arbitrary shell disabled by default  
- Elevation path only for allowlisted readonly probes initially  

**Complexity:** H

## Implementation risks (sequence-level)

1. **Skipping mediated runner** and shelling out raw — do not; Phase D is the security core.  
2. **Putting HMAC secret in repo or agent config** — never.  
3. **UI-only security** without Host enforcement — insufficient.  
4. **Scope creep into R6.6 migration** — hard freeze: no private migration code in R6.5.  
5. **Breaking Claude independence** by allowing auditor writes “for convenience.”  

---

## Mapping to future R6.6

R6.6 Real Migration + Writer Cutover should be expressed as:

- new envelope risk_class = HIGH_CONSEQUENCE  
- authorized_operations mostly read + controlled migration tokens  
- **every** writer/migration/key op in `high_consequence_gates`  
- still Owner UI nested approvals  
- still no agent self-auth  

R6.5 only needs the **gate framework**, not the migration operations themselves.

---

## Stop conditions during implementation

Stop and return to Owner if:

- any self-auth test fails  
- desire arises to grant agents free elevated shell  
- migration/private state appears in R6.5 scope  
- desktop promotion requested as “side effect”

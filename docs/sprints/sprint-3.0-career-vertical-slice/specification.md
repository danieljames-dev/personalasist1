# Sprint 3.0 first-usable Career demo specification

Directive `AION-S3-M1-FIRST-USABLE-CAREER-DEMO` completes the bounded local vertical slice from
explicit owner input through a review-gated preparation draft. The implementation composes the
accepted privacy, Identity, Object, canonical, resource-limit, Career Input/Evidence, and Job
Posting boundaries; it adds no new architectural center.

Deliverables are transparent deterministic Job Matching, evidence-backed Application Preparation,
the explicit-root local Career CLI, a complete neutral synthetic temporary demo, local export and
reload, test/architecture evidence, documentation, normal source pushes, and isolated backup
restore proof. Domain state remains private and ignored. All synthetic examples are intentionally
unrelated to known owner history.

The milestone stops before real owner-data ingestion. Job discovery, URLs, networking, models,
embeddings, vector databases, submission, email, forms, signing, attestation, and employer contact
are outside scope. Status remains Reference Candidate; DG-3 and DG-4b remain Open; the Universal
Object Contract remains Pre-stable; normative fixtures remain unauthorized.

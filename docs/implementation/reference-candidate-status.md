# Reference Candidate status

The first usable Career demo is a bounded local, single-owner **Reference Candidate**. It proves
deterministic behavior on small neutral synthetic inputs. It does not claim normative conformance,
production readiness, representative workload capacity, hiring efficacy, or safe processing of
hostile/public data.

Implemented: explicit local input; CareerSource/CareerFact provenance; CareerProfile; owner-supplied
JobPosting import; transparent integer matching; cited owner-review application preparation; local
CLI; versioned export/reload; deterministic rerun; and isolated source-backup restore verification.

Not implemented: job discovery, URL fetch, application submission, email, forms, signing,
attestation, employer interaction, authentication/remote access, models, embeddings, vector stores,
networking, or telemetry. Real owner-data ingestion was not executed and requires a later explicit
Founder decision.

Gate state is unchanged: DG-3 Open; DG-4b Open; Universal Object Contract Pre-stable; normative
fixtures unauthorized. Synthetic tests are regression evidence only and do not close those gates.

# Security Policy

AION is pre-release and currently has no public vulnerability intake address. Until
one is established, do not publish suspected vulnerabilities in public issue trackers.
Report them privately to the repository owner.

Security-sensitive work requires a threat-model update covering assets, actors,
trust boundaries, abuse cases, controls, verification, and residual risk. Secrets and
owner data must never be placed in source, fixtures, logs, events, or bug reports.

Supported security versions will be published before the first external release.
